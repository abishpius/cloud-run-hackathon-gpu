CLOUD RUN GPU HACKATHON SUBMISSION - PROJECT DESCRIPTION

Project Name: Healthcare Assistant (Dr. Cloud)
Category: GPU Category
Region: us-central1 (GPU-enabled)

=============================================================================
OVERVIEW
=============================================================================

Healthcare Assistant (Dr. Cloud) is an AI-powered primary care companion that
leverages Google Cloud Run with NVIDIA L4 GPUs to run the open-source MedGemma
model. The application provides accessible, intelligent healthcare guidance
through a conversational interface, making medical information more
understandable for everyday users.

=============================================================================

=============================================================================

1. INTELLIGENT CHAT INTERFACE
   - Real-time conversation with AI healthcare assistant

2. HEALTHCARE CAPABILITIES

3. USER EXPERIENCE ENHANCEMENTS
   - Clean, intuitive Streamlit-based interface
   - Mobile-responsive design
   - Real-time typing indicators
   - Conversation history tracking
   - New conversation capability
   - Medical disclaimer and emergency information
   - Backend health status monitoring

INTELLIGENT RESPONSE PROCESSING:

The application includes a sophisticated JSON detection system that identifies
when the AI model returns technical JSON output instead of natural language.
When detected, the system automatically:
1. Hides the JSON from the user
2. Shows a "still thinking" message
3. Sends the JSON back to the model with the prompt: "Can you explain this
   to a layperson"
4. Displays the user-friendly explanation

This ensures users always receive accessible, understandable information
rather than raw technical data.

Cloud Run's GPU capabilities with open-source medical AI models to create an

architecture.

healthcare, making medical information more accessible and understandable
for everyday users while maintaining appropriate safety disclaimers and
encouraging professional medical consultation when needed.
